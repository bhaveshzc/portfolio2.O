# Project: Portfolio Mobile Responsiveness

## Overview
Comprehensive mobile adaptation of the existing full-stack developer portfolio for Bhavesh Bisht. The goal is to make all sections, interactive widgets, animations, subpages, and navigation fully responsive on all mobile devices (from 320px up to 768px) while strictly preserving the desktop layout, aesthetics, and animations.

## Core Rules & Constraints
1. **Preserve Desktop Version**: Keep existing styling, spacing, layout, and visual identity intact for `> 768px`.
2. **Zero Horizontal Overflow**: Ensure no horizontal scrolling exists on any mobile screen.
3. **Dedicated Mobile Navigation**: Logo on the left, animated hamburger menu on the right with full stacked vertical links.
4. **Fluid Adaptation**: Responsive typography using `clamp()`, flexible grids, percentage widths, and mobile-friendly touch targets.

## Scope
- **Route 1 (`/`)**: Hero section (scroll animations, CurvedLoop, image), Introduction Bento Grid, Visitor Badge, Tech Marquee, Split Cards, Social Dock, Contact Section & Form.
- **Route 2 (`/journey` / `/about`)**: About Me philosophy cards, Skills & Technologies marquee table, Career & Education Timeline.
- **Route 3 (`/projects`)**: Featured Projects cards, tags, highlights, and stacked action buttons.
- **Route 4 (`/contact`)**: Top identity pill & social buttons, Email capsule, Message form, OriginCalendar 3-column booking component.
