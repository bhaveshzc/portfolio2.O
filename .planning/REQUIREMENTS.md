# Requirements: Mobile Responsiveness

## Mobile Specifications
- **Target Screen Sizes**: 320px, 360px, 375px, 390px, 412px, 430px, 480px, 768px.
- **Desktop Invariance**: All screens >= 769px remain unchanged in layout, typography, animations, and spacing.

## Functional Requirements
- [ ] **NAV-01**: Mobile Navigation — Logo on left, hamburger toggle on right. Closes on backdrop click or navigation.
- [ ] **HERO-01**: Hero Section — Fix 150vw overflow in hero image layer. Fluidly scale "Full-Stack" script title, CurvedLoop developer loop, and floating action words.
- [ ] **BENTO-01**: Bento Grid & Introduction — Responsive top profile card, centered avatar, seamless tech marquee, 1-column split action cards ("My Journey" & "My Projects"), balanced social pill dock.
- [ ] **JOURNEY-01**: Journey Page — Single column philosophy cards, responsive skills marquee table rows, timeline stem & dot alignment, scalable university/org logos.
- [ ] **PROJECTS-01**: Projects Page — Stacked glass project cards, responsive highlight points, full-width action buttons on mobile.
- [ ] **CONTACT-01**: Contact Page & Section — Single column contact form, overflowing email address prevention on 320px, responsive tab switcher, 1-column OriginCalendar booking widget with accessible date buttons and modal dialog.
- [ ] **GLOBAL-01**: Overflow Prevention — Zero horizontal scroll across all routes and viewports.
